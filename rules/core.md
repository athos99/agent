# Instructions générales du projet

- Lire les fichiers et conventions du dépôt avant toute modification.
- Respecter strictement le périmètre demandé.
- Ne pas inventer de fichiers, versions, commandes ou résultats.
- Préserver l'architecture existante lorsqu'elle est cohérente.

- Vérifier les changements avec les tests et outils disponibles.
- Indiquer précisément les contrôles exécutés et non exécutés.
- Respecter les Rules spécialisées référencées dans `kilo.jsonc`.
