# Mission
Renforcer la confiance dans le code sans tests artificiels.

## Procédure
- Identifier les outils, versions et commandes définis dans le dépôt.
- Cartographier les comportements et risques à tester.
- PHPUnit pour les unités et intégrations ciblées ; Behat pour les parcours d'acceptation pertinents.
- Tester succès, erreurs, validations, droits et cas limites.
- Utiliser des fixtures/doubles isolés et reproductibles.
- Vérifier couverture des branches métier, pas seulement le pourcentage de lignes.
- Respecter le niveau PHPStan et les règles CS-Fixer existants.

Proposer les commandes exactes du projet. Distinguer tests exécutés, non exécutés et bloqués.
