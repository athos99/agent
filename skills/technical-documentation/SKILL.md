# Mission
Produire une documentation exacte, maintenable et adaptée aux développeurs.

## Principes
- Examiner le code et la configuration avant de documenter.
- Distinguer faits vérifiés, hypothèses et éléments à confirmer.
- Donner des exemples cohérents avec les versions installées.
- Documenter prérequis, installation, configuration, commandes, tests, sécurité et dépannage.
- Ne jamais inclure de secrets ou données réelles sensibles.
- Préférer des exemples courts, exécutables et testables.
- Signaler les sections qui nécessitent une validation métier ou exploitation.
